# Contributing to Vision Aid

Thank you for your interest in contributing to Vision Aid! We welcome contributions from everyone to help make vision accessibility better for all.

## **How Can I Contribute?**

### **1. Reporting Bugs**
If you find a bug, please create a new issue on GitHub with:
- A clear description of the issue.
- Steps to reproduce the bug.
- (Optional) Screenshots or video recordings.
- Your environment details (Browser, OS, Node version).

### **2. Suggesting Enhancements**
We love new ideas! Before creating a feature request, please search existing issues.
If you have a new idea, open an issue with the **enhancement** label.

### **3. Pull Requests**
1.  **Fork the repository** to your own GitHub account.
2.  **Clone the project** to your local machine.
3.  **Create a branch** for your feature or fix: `git checkout -b feature/amazing-feature`.
4.  **Make your changes** and commit them: `git commit -m 'feat: Add some amazing feature'`.
    - Please follow [Conventional Commits](https://www.conventionalcommits.org/).
5.  **Push to the branch**: `git push origin feature/amazing-feature`.
6.  **Open a Pull Request** against the **target branch** (`develop` or `main`).

## **Development Setup**

1.  **Prerequisites**:
    - Node.js (v18+)
    - MongoDB (Running locally or count string)
    - Python 3.9+ (For YOLO service)

2.  **Installation**:
    ```bash
    # Clone the repo
    git clone https://github.com/Start-Vision-Aid/Vision-Aid.git
    cd Vision-Aid

    # Run setup script (Windows)
    ./start-project.ps1
    ```

## **Code Style**
- **JavaScript**: Use ESLint configuration provided. Run `npm run lint`.
- **Python**: Follow PEP 8 guidelines.
